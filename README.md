# Rakuten

Trang web thương mại điện tử tĩnh mô phỏng Rakuten với giao diện hiện đại, hỗ trợ lọc sản phẩm và tương tác giỏ hàng cơ bản.

## Cấu trúc dự án

```
.
├── index.html          # Trang chủ với các khu vực hero, danh mục, sản phẩm, blog...
├── assets
│   ├── css
│   │   └── styles.css  # Toàn bộ stylesheet
│   ├── js
│   │   └── main.js     # Logic lọc sản phẩm và cập nhật giỏ hàng
│   └── images
│       └── .gitkeep
```

## Sử dụng

Chỉ cần mở `index.html` trong trình duyệt để xem giao diện. Không cần bước build.
